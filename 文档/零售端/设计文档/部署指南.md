# 零售商城 — 部署指南

## 前置条件

- Node.js >= 18
- pnpm >= 8
- Cloudflare 账号（用于 Workers 和 Pages）
- Supabase 项目已创建并完成基础迁移（001-008）
- 微信开放平台小程序账号（AppID + AppSecret）
- 微信开发者工具

## 项目架构

| 模块 | 技术栈 | 部署目标 |
|------|--------|----------|
| API | Hono + Cloudflare Workers | Cloudflare Workers |
| H5 批发用户端 | Vue 3 + Vant 4 | Cloudflare Pages |
| 零售 H5 用户端 | Taro 4 + Vue 3 + NutUI | Cloudflare Pages |
| 零售微信小程序 | Taro 4 + Vue 3 + NutUI | 微信开放平台 |
| Admin 管理后台 | React 18 + Ant Design 5 | Cloudflare Pages |
| 数据库 | Supabase PostgreSQL | Supabase Cloud |

## 2. API 部署（扩展）

### 2.1 配置新增 Secrets

```bash
cd api
# 微信小程序配置
wrangler secret put WX_APPID
wrangler secret put WX_SECRET
# 零售端 JWT 密钥
wrangler secret put JWT_SECRET
```

### 2.2 更新 wrangler.toml

将 `WX_APPID` 和 `WX_SECRET` 添加到 `vars` 段（非敏感）或通过 `wrangler secret` 配置（敏感信息）。

### 2.3 部署

```bash
pnpm run deploy:api
# 或
cd api && npx wrangler deploy
```

### 2.4 验证

```bash
# 测试零售端首页（公开路由）
curl https://online-shop-api.<your-subdomain>.workers.dev/api/retail/home
```

## 3. 零售 H5 部署

### 3.1 配置环境变量

在 `retail/.env.production` 中设置：

```env
TARO_APP_API_BASE_URL=https://online-shop-api.<your-subdomain>.workers.dev
```

### 3.2 构建 H5

```bash
cd retail && pnpm build:h5
```

构建产物在 `retail/dist/` 目录。

### 3.3 部署到 Cloudflare Pages

**方式一：CLI 部署**

```bash
npx wrangler pages deploy retail/dist --project-name=online-shop-retail
```

**方式二：Git 集成（推荐）**

1. 将代码推送到 GitHub
2. 在 Cloudflare Dashboard → Pages → Create a project → Connect to Git
3. 配置：
   - Build command: `cd retail && pnpm build:h5`
   - Build output directory: `retail/dist`
   - Environment variables: 填入 `TARO_APP_API_BASE_URL`

## 4. 零售微信小程序部署

### 4.1 构建小程序

```bash
cd retail && pnpm build:weapp
```

构建产物在 `retail/dist/` 目录。

### 4.2 微信开发者工具

1. 打开微信开发者工具
2. 导入 `retail/dist/` 目录
3. 配置 AppID
4. 上传代码

### 4.3 小程序配置

在微信公众平台 → 开发管理 → 开发设置中完成：

- 配置服务器域名（request 合法域名）
- 配置业务域名（web-view 域名）
- 配置 AppID 和 AppSecret

### 4.4 提交审核

在微信公众平台提交审核并上线。

## 8. 常见问题

### Q: 微信登录报错 "invalid code"
A: code 有效期 5 分钟，确保 code2session 调用及时。检查 WX_APPID 和 WX_SECRET 配置正确。

### Q: 小程序 request 域名报错
A: 在微信公众平台 → 开发管理 → 开发设置 → 服务器域名 中配置 request 合法域名。

### Q: Taro H5 模式路由 404
A: 确认使用 hash 路由模式，Cloudflare Pages 会自动处理 SPA fallback。

### Q: 积分操作报错 "deadlock detected"
A: 积分 RPC 函数使用 FOR UPDATE 行锁，确保在事务中调用。如仍有问题检查是否有并发操作未使用 RPC。

### Q: 运费计算返回 0
A: 检查 shipping_fees 表中是否配置了对应城市的运费规则，以及 system_settings 中的 default_shipping_fee 值。
