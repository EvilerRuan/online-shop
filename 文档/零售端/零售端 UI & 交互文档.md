# 零售商城 — 零售端 UI & 交互文档

## 0. 全局规则

### 0.1 跨端适配
- H5 模式：devServer port 10086，hash 路由
- 小程序模式：标准微信小程序构建
- TabBar 图标使用 SVG 格式
- 微信登录需平台判断（`process.env.TARO_ENV === 'weapp'`）
- 分享功能仅小程序可用，H5 降级为复制链接

### 0.2 登录态管理
- 启动时检查 Token → 有效进首页 / 无效跳登录
- 请求拦截器自动附加 Bearer Token
- 401 响应 → 清 Token → 跳登录页

### 0.3 渠道过滤
- 商品列表/搜索仅展示 sales_channel 为 'retail' 或 'both' 的商品
- 订单列表仅展示 channel=retail 的订单

## 1. 登录/注册页

### 页面元素
- Logo + 应用名称
- 微信一键登录按钮（仅小程序环境显示）
- 手机号输入框（必填，格式校验）
- 验证码输入框 + 获取验证码按钮（60秒倒计时）
- 登录/注册按钮
- 推荐码提示（如携带 ref 参数，显示"好友推荐注册"）

### 交互逻辑
1. 微信登录 → POST /api/auth/wx-login（code → openid → 查找/创建用户 → JWT）
2. 验证码登录：
   - 点击"获取验证码" → POST /api/auth/send-code（模拟，固定 123456）
   - 输入验证码 → POST /api/auth/sms-login
3. 成功 → 保存 Token，跳转首页
4. 首次注册自动赠送积分（Toast 提示"注册成功，获得 xxx 积分"）
5. 如携带 ref 参数 → 建立推荐关系 → 奖励推荐人积分
6. 失败 → 提示错误信息

## 2. 首页（TabBar 第1个）

### 页面元素
- 顶部搜索框（点击跳转搜索页）
- Banner 轮播图（自动轮播，数据来源 retail_banners）
- 金刚区图标区（数据来源 retail_quick_icons，最多 10 个入口）
- 热销推荐商品列表（网格 2 列，数据来源 retail_home_products）

### 交互逻辑
1. 页面加载 → GET /api/retail/home（聚合 banners + quick_icons + hot_products）
2. Banner 点击 → 跳转配置链接
3. 金刚区点击 → 跳转对应页面
4. 商品点击 → 跳转商品详情页
5. 下拉刷新 → 重新调用 /api/retail/home 更新数据
6. 错误处理：
   - 网络错误 → 显示重试按钮
   - 数据为空 → 显示空状态图

## 4. 购物车页（TabBar 第3个）

### 页面元素
- 购物车商品列表
  - 商品图片
  - 商品名称 + 规格名称
  - 零售价
  - 数量选择器（+ / - 按钮）
  - 小计金额
  - 删除按钮
- 底部操作栏
  - 全选复选框
  - 合计金额
  - 结算按钮（显示已选数量）

### 交互逻辑
1. 页面加载 → 从本地存储读取购物车数据（Pinia useCartStore）
2. 未登录 → 显示空购物车 + 引导登录
3. 修改数量 → 实时更新小计和总价（最小 1，最大库存）
4. 删除商品 → 弹窗二次确认 → 确认后移除
5. 全选/取消全选 → 切换所有商品选中状态
6. 点击"结算" → 携带已选商品跳转确认订单页
7. 购物车为空 → 显示空状态图 + "去逛逛"按钮

## 9. 确认订单页

### 页面元素
- 收货地址卡片（默认地址，可点击切换）
- 商品清单（图片、名称、规格、数量、小计）
- 运费信息（自动计算，显示运费金额 / "免运费"）
- 订单总金额（商品合计 + 运费）
- 备注输入框
- "提交订单"按钮

### 交互逻辑
1. 页面加载 → 获取默认地址 + 计算运费（GET /api/retail/shipping/calculate）
2. 点击地址 → 跳转地址列表页选择/新增地址
3. 地址变更 → 重新计算运费
4. 运费计算规则：精确匹配省+市 → 匹配省+city='' → 默认运费
5. 满额免运费提示（如"满 ¥99 免运费，还差 ¥xx"）
6. 点击"提交订单"：
   - 调用 POST /api/retail/orders（含地址、商品列表、备注）
   - 成功 → Toast "下单成功" → 跳转订单列表页
   - 库存不足 → Toast "xxx 商品库存不足" → 停留当前页
   - 网络错误 → Toast 提示 → 停留当前页

## 10. 地址管理

### 10.1 地址列表页

#### 页面元素
- 地址列表：收件人、电话、省市区+详细地址、默认标签
- 每个地址：编辑图标、删除图标
- "新增地址"按钮

#### 交互逻辑
1. 页面加载 → GET /api/addresses
2. 点击编辑 → 跳转地址编辑页
3. 点击删除 → 二次确认 → DELETE /api/addresses/:id
4. 设为默认 → PUT /api/addresses/:id/default
5. 点击"新增地址" → 跳转地址编辑页（空表单）
6. 从确认订单页进入时：点击地址 → 返回确认订单页（携带地址 ID）

### 10.2 地址编辑页

#### 页面元素
- 收件人输入框（必填）
- 联系电话输入框（必填，手机号校验）
- 省/市/区三级联动选择器
- 详细地址输入框（必填）
- "设为默认地址"开关
- "保存"按钮

#### 交互逻辑
1. 编辑模式 → 回填已有地址数据
2. 保存 → POST/PUT /api/addresses → 成功后返回地址列表
3. 校验不通过 → 显示对应字段错误提示
