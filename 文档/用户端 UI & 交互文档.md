用户端 UI & 交互文档

1️⃣ 登录页

页面元素

手机号输入框（必填，格式校验）
密码输入框（必填，最小6位）
登录按钮（输入合法后可用）
忘记密码链接
背景图/Logo

交互逻辑

点击登录 → POST /api/auth/login
成功 → 保存 Session，跳转首页
失败 → 提示错误信息（账号不存在/密码错误/账号被禁用）
2️⃣ 首页

页面元素

顶部搜索框（点击跳转搜索页）
Banner轮播图（自动轮播，点击跳转链接）
金刚区图标区（最多10个入口）
热销推荐商品列表（网格2列）

交互逻辑

Banner点击 → 跳转对应链接
金刚区点击 → 跳转对应页面
商品点击 → 跳转商品详情页
下拉刷新 → 调用 /api/home 更新数据
3️⃣ 分类页

页面元素

左侧一级分类列表
右侧二级分类网格（存在二级分类时显示）

交互逻辑

点击一级分类：
有二级分类 → 显示右侧网格
无二级分类 → 直接跳转商品列表页
点击二级分类 → 跳转商品列表页
4️⃣ 商品列表页

页面元素

当前分类名称
商品网格列表（图片、名称、价格、销量、购物车图标）
排序控件（综合、价格升序/降序、销量降序）
分页加载（滚动到底部自动加载）

交互逻辑

点击商品条目（图片、名称、购物车图标） → 跳转商品详情页
排序切换 → 调用 /api/products 更新数据
滚动到底 → 分页加载下一页数据
5️⃣ 商品详情页（主体）

页面元素

商品图片轮播
商品名称
商品编号
条码
销量
价格
库存
最低订购量
商品描述（富文本，可展开/收起）
底部操作条：加入购物车按钮

交互逻辑

点击“加入购物车” → 打开 加购弹框
页面本身只显示商品信息，不处理规格、数量或备注
6️⃣ 加购弹框（独立交互界面）

页面元素

弹框顶部：商品标题 + 商品小图
规格选择按钮组
多规格（个/包/件）
默认选中第一个
切换规格 → 更新价格、库存、最低订购量
数量选择器
加减按钮
最小值 = 当前规格最低订购量
最大值 = 当前规格库存
步长 = 1
数量变化 → 实时计算总金额
备注输入框（可选）
底部操作按钮：
确定加入购物车 → POST /api/cart，提示“添加成功”，关闭弹框
取消 → 关闭弹框，不提交数据

交互逻辑

切换规格 → 更新价格、库存、最低订购量
修改数量 → 实时更新总金额
输入备注 → 绑定到加购请求
点击确定 → 发起加购 API 请求 → 成功提示 → 关闭弹框
点击取消 → 关闭弹框
7️⃣ 购物车页

页面元素

商品列表（图片、名称、规格、单价、数量、小计）
数量修改按钮（加减）
删除按钮（弹窗二次确认）
全选/取消全选
底部总价 + 结算按钮

交互逻辑

修改数量 → 校验最小/最大 → 更新小计和总价
删除商品 → 二次确认 → 调用 DELETE /api/cart/{id}
结算按钮 → 跳转确认订单页，携带选中商品
8️⃣ 确认订单页

页面元素

收货地址展示（可切换/新增）
商品清单（名称、规格、数量、小计）
订单总金额
备注输入框
提交订单按钮

交互逻辑

点击提交 → POST /api/orders
库存足够 → 生成订单，清空购物车，跳转订单列表页
库存不足 → 提示“xxx商品库存不足”，停留当前页
地址切换/新增 → 调用地址 API，刷新列表
9️⃣ 收货地址管理页

页面元素

地址列表（收件人、电话、详细地址、编辑、删除按钮）
新增/编辑地址表单（收件人、电话、三级联动省市区、详细街道、是否默认）
默认地址置顶

交互逻辑

编辑/删除 → PUT/DELETE /api/address/{id}
新增 → POST /api/address
设置默认 → 更新数据库，刷新列表
10️⃣ 订单列表页

页面元素

Tab切换：全部、待付款、待发货、待收货、已完成、已取消
每个订单显示：订单号、下单时间、总金额、状态、商品缩略图（最多3个）
取消订单按钮（待付款状态）
确认收货按钮（待收货状态）

交互逻辑

Tab切换 → 刷新列表数据
点击订单 → 跳转订单详情页
取消订单 → POST /api/orders/{id}/cancel → 状态变为已取消
确认收货 → POST /api/orders/{id}/confirm → 状态变为已完成
11️⃣ 订单详情页

页面元素

订单信息：订单号、下单时间、状态、收货地址
商品清单：名称、规格、单价、数量、小计
底部操作按钮（取消订单/确认收货）

交互逻辑

操作按钮点击 → 调用对应 API → 更新状态 → 刷新页面
12️⃣ 个人中心页

页面元素

用户信息卡片（用户名、用户编号）
我的订单入口（全部订单、待付款、待发货、待收货，显示角标数量）
地址管理入口
商家简介、商家公告、买家须知入口
退出登录按钮

交互逻辑

点击订单入口 → 跳转对应订单列表页
地址管理 → 跳转地址管理页
富文本内容 → GET /api/system_settings
退出登录 → 清除 Session → 返回登录页
