### 页面布局

```
┌────────────────────┐
│ ┌──┐ 杀虫剂        │  ← 弹框顶部：小图 + 商品名称
│ │图片│             │
│ └──┘             │
├────────────────────┤
│ [个]  [件]          │  ← 规格按钮组（默认选中第一个）
│                     │     选中：绿色背景+白字
│                     │     未选中：白色背景+灰边框
├────────────────────┤
│ -   24   +         │  ← 数量选择器
│                     │     左减右加，中间数字显示实际商品个数
│                     │     按一次 + 增加当前规格对应的数量
│ 单价: ¥2.60  数量: 24 │
│ 金额: ¥62.40       │  ← 实时更新总金额
├────────────────────┤
│ ┌────────────────┐ │
│ │ 备注            │ │  ← 多行文本输入框
│ └──────────────── │
────────────────────┤
│     确定            │  ← 绿色满宽按钮
└────────────────────┘
```

### 组件映射

| 区域 | Vant 组件 | 说明 |
|------|-----------|------|
| 弹框 | `<van-action-sheet>` | 底部弹出，`v-model:show="showAddCart"` |
| 商品信息 | `<van-row>` 布局 | 左侧 `<van-image width="60" height="60">`，右侧商品名称 |
| 规格按钮组 | `<van-radio-group v-model="selectedSkuId" direction="horizontal">` | 按钮用 `<van-radio name="sku_id">`，自定义样式为按钮形态 |
| 数量选择器 | 自定义 `+/-` 按钮 | 按一次 `+` 增加当前规格对应的 `quantity` 值，`-` 同理减少。中间数字显示实际商品个数。最小值 = 最低订购量，最大值 = 库存 |
| 金额展示 | 纯文本计算 | 单价 × 实际商品个数 = 总金额，数量变化时自动重新计算 |
| 备注 | `<van-field v-model="remark" type="textarea" rows="2" placeholder="备注" />` | 可选输入 |
| 确定按钮 | `<van-button type="primary" block @click="handleConfirm">确定</van-button>` | 绿色满宽 |
| 取消 | 点击弹框外部或遮罩关闭 | 不提交数据 |

### 交互逻辑

1. 点击 "加入购物车" → 打开弹框
2. 切换规格 → 更新单价、库存、最低订购量，数量重置为最低订购量（按规格 quantity 对齐）
3. 修改数量 → 按当前规格的 `quantity` 步长增减，显示实际商品个数；实时更新总金额（单价 × 实际商品个数）
4. 输入备注 → 绑定到加购请求
5. 点击确定 → `POST /api/cart` → "添加成功" Toast → 关闭弹框
6. 点击取消/外部 → 关闭弹框，不提交
