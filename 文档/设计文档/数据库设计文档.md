# 线上批发商城 H5 系统 — 数据库设计文档

## 1. 数据库概览

使用 Supabase PostgreSQL 数据库，所有表均在 `public` schema 下。

### 1.1 ER 关系图

```
auth.users (Supabase 内置)
    │
    ├── profiles (用户档案，1:1)
    │
    ├── cart (购物车，1:N)
    │
    ├── orders (订单，1:N)
    │     └── order_items (订单商品，1:N)
    │
    └── addresses (收货地址，1:N)

categories (分类，自引用树形)
    │
    └── products (商品，N:1)
          │
          └── product_skus (商品规格，1:N)
                │
                ├── cart (N:1)
                │
                └── order_items (N:1)

banners (轮播图，独立)
quick_icons (金刚区图标，独立)
home_products (热销推荐商品，多对多)
system_settings (系统设置，KV 结构)
```

### 1.2 表清单

| 序号 | 表名 | 用途 | 记录规模预估 |
|------|------|------|-------------|
| 1 | profiles | 用户档案 | 百~千级 |
| 2 | categories | 商品分类 | 十~百级 |
| 3 | products | 商品信息 | 百~千级 |
| 4 | product_skus | 商品规格 | 千级 |
| 5 | cart | 购物车 | 千级（动态） |
| 6 | orders | 订单 | 千~万级 |
| 7 | order_items | 订单商品明细 | 万级 |
| 8 | addresses | 收货地址 | 千级 |
| 9 | banners | 轮播图配置 | 十级 |
| 10 | quick_icons | 金刚区图标配置 | 十级 |
| 11 | home_products | 热销推荐商品 | 十级 |
| 12 | system_settings | 系统设置 | 个位数 |

## 2. 表结构详细设计

### 2.1 profiles — 用户档案表

扩展 Supabase auth.users，存储业务相关的用户信息。

```sql
CREATE TABLE profiles (
    id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    user_no BIGSERIAL UNIQUE,
    username TEXT NOT NULL,
    phone TEXT NOT NULL UNIQUE,
    role TEXT NOT NULL DEFAULT 'user' CHECK (role IN ('user', 'admin')),
    status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'disabled')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_profiles_user_no ON profiles(user_no);
CREATE INDEX idx_profiles_phone ON profiles(phone);
CREATE INDEX idx_profiles_role ON profiles(role);

COMMENT ON TABLE profiles IS '用户档案表';
COMMENT ON COLUMN profiles.id IS '用户ID，关联 auth.users';
COMMENT ON COLUMN profiles.user_no IS '用户编号（自增，用于展示，如 18266）';
COMMENT ON COLUMN profiles.username IS '用户名';
COMMENT ON COLUMN profiles.phone IS '手机号（唯一）';
COMMENT ON COLUMN profiles.role IS '角色：user=普通用户, admin=管理员';
COMMENT ON COLUMN profiles.status IS '状态：active=启用, disabled=禁用';
```

### 2.2 categories — 分类表

支持两级分类（一级分类 parent_id = NULL，二级分类 parent_id 指向一级）。

```sql
CREATE TABLE categories (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    parent_id BIGINT REFERENCES categories(id) ON DELETE CASCADE,
    sort_order INT NOT NULL DEFAULT 0,
    show_in_client BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_categories_parent_id ON categories(parent_id);
CREATE INDEX idx_categories_sort ON categories(sort_order);

COMMENT ON TABLE categories IS '商品分类表（支持两级）';
COMMENT ON COLUMN categories.parent_id IS '父分类ID，NULL 表示一级分类';
COMMENT ON COLUMN categories.sort_order IS '排序权重，越小越靠前';
COMMENT ON COLUMN categories.show_in_client IS '是否在用户端显示';
```

### 2.3 products — 商品表

```sql
CREATE TABLE products (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    product_no TEXT NOT NULL UNIQUE,
    barcode TEXT,
    category_id BIGINT NOT NULL REFERENCES categories(id) ON DELETE RESTRICT,
    main_image TEXT,
    description TEXT DEFAULT '',
    sales_count INT NOT NULL DEFAULT 0,
    status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'inactive')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_products_category_id ON products(category_id);
CREATE INDEX idx_products_status ON products(status);
CREATE INDEX idx_products_product_no ON products(product_no);
CREATE INDEX idx_products_barcode ON products(barcode);
CREATE INDEX idx_products_sales_count ON products(sales_count DESC);

COMMENT ON TABLE products IS '商品表';
COMMENT ON COLUMN products.product_no IS '商品编号（唯一，自动生成）';
COMMENT ON COLUMN products.barcode IS '条码（可选）';
COMMENT ON COLUMN products.main_image IS '商品主图URL';
COMMENT ON COLUMN products.description IS '商品详情（富文本HTML）';
COMMENT ON COLUMN products.sales_count IS '累计销量';
COMMENT ON COLUMN products.status IS '状态：active=上架, inactive=下架';
```

### 2.4 product_skus — 商品规格表

每个商品可有多个规格（如：个/包/件），每个规格独立的价格、库存、最低订购量。

```sql
CREATE TABLE product_skus (
    id BIGSERIAL PRIMARY KEY,
    product_id BIGINT NOT NULL REFERENCES products(id) ON DELETE CASCADE,
    sku_name TEXT NOT NULL,
    price DECIMAL(10,2) NOT NULL CHECK (price >= 0),
    stock INT NOT NULL DEFAULT 0 CHECK (stock >= 0),
    min_order_qty INT NOT NULL DEFAULT 1 CHECK (min_order_qty >= 1),
    sort_order INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_skus_product_id ON product_skus(product_id);

COMMENT ON TABLE product_skus IS '商品规格表';
COMMENT ON COLUMN product_skus.sku_name IS '规格名称（如：个/包/件）';
COMMENT ON COLUMN product_skus.price IS '单价';
COMMENT ON COLUMN product_skus.stock IS '库存数量';
COMMENT ON COLUMN product_skus.min_order_qty IS '最低订购量';
```

### 2.5 cart — 购物车表

```sql
CREATE TABLE cart (
    id BIGSERIAL PRIMARY KEY,
    user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
    product_id BIGINT NOT NULL REFERENCES products(id) ON DELETE CASCADE,
    sku_id BIGINT NOT NULL REFERENCES product_skus(id) ON DELETE CASCADE,
    quantity INT NOT NULL CHECK (quantity >= 1),
    remark TEXT DEFAULT '',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_cart_user_id ON cart(user_id);
CREATE UNIQUE INDEX idx_cart_user_product_sku ON cart(user_id, product_id, sku_id);

COMMENT ON TABLE cart IS '购物车表';
COMMENT ON COLUMN cart.quantity IS '购买数量';
COMMENT ON COLUMN cart.remark IS '用户备注';
```

**唯一约束**：同一用户 + 同一商品 + 同一规格 只有一条记录，重复加购时累加数量。

### 2.6 orders — 订单表

```sql
CREATE TABLE orders (
    id BIGSERIAL PRIMARY KEY,
    order_no TEXT NOT NULL UNIQUE,
    user_id UUID NOT NULL REFERENCES profiles(id),
    total_amount DECIMAL(10,2) NOT NULL CHECK (total_amount >= 0),
    status TEXT NOT NULL DEFAULT 'pending_payment'
        CHECK (status IN ('pending_payment', 'pending_shipment', 'pending_receipt', 'completed', 'cancelled')),
    remark TEXT DEFAULT '',
    recipient_name TEXT NOT NULL,
    recipient_phone TEXT NOT NULL,
    address TEXT NOT NULL,
    shipping_no TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_orders_status ON orders(status);
CREATE INDEX idx_orders_order_no ON orders(order_no);
CREATE INDEX idx_orders_created_at ON orders(created_at DESC);

COMMENT ON TABLE orders IS '订单表';
COMMENT ON COLUMN orders.order_no IS '订单编号（格式：yyyyMMddHHmmss + 6位随机数）';
COMMENT ON COLUMN orders.status IS '订单状态';
COMMENT ON COLUMN orders.address IS '收货完整地址';
COMMENT ON COLUMN orders.shipping_no IS '物流单号（发货后填写）';
```

**订单状态流转：**

```
                    用户取消
                       │
                       ▼
                 ┌──────────┐
                 │cancelled │
                 └──────────┘
                       ▲
                       │ 用户取消
                       │
┌────────────────┐  提交订单  ┌─────────────────┐  管理员发货  ┌─────────────────┐
│pending_payment │ ─────────→ │pending_shipment │ ──────────→ │pending_receipt  │
│  (待付款)       │           │  (待发货)        │            │  (待收货)        │
└────────────────┘           └─────────────────┘            └────────┬────────┘
                                                                     │
                                                            用户确认收货
                                                                     │
                                                                     ▼
                                                            ┌────────────────┐
                                                            │   completed    │
                                                            │   (已完成)      │
                                                            └────────────────┘
```

### 2.7 order_items — 订单商品明细表

```sql
CREATE TABLE order_items (
    id BIGSERIAL PRIMARY KEY,
    order_id BIGINT NOT NULL REFERENCES orders(id) ON DELETE CASCADE,
    product_id BIGINT NOT NULL,
    sku_id BIGINT NOT NULL,
    product_name TEXT NOT NULL,
    sku_name TEXT NOT NULL,
    main_image TEXT,
    price DECIMAL(10,2) NOT NULL,
    quantity INT NOT NULL CHECK (quantity >= 1),
    subtotal DECIMAL(10,2) NOT NULL,
    remark TEXT DEFAULT '',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_order_items_order_id ON order_items(order_id);

COMMENT ON TABLE order_items IS '订单商品明细表';
COMMENT ON COLUMN order_items.product_name IS '商品名称快照（下单时）';
COMMENT ON COLUMN order_items.sku_name IS '规格名称快照';
COMMENT ON COLUMN order_items.price IS '下单时单价快照';
COMMENT ON COLUMN order_items.subtotal IS '小计 = price × quantity';
```

**设计说明**：order_items 中的 product_name、sku_name、price、main_image 为下单时的快照数据，不随商品后续修改而变化，保证订单历史准确性。product_id 和 sku_id 不设外键约束（商品可能被删除，但订单记录需保留）。

## 3. 通用字段规范

### 3.1 时间戳

所有表统一使用 `TIMESTAMPTZ` 类型存储时间，字段名：
- `created_at` — 记录创建时间
- `updated_at` — 记录更新时间

### 3.2 自动更新 updated_at

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

为每张需要自动更新的表创建触发器：

```sql
CREATE TRIGGER update_profiles_updated_at BEFORE UPDATE ON profiles
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_categories_updated_at BEFORE UPDATE ON categories
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_products_updated_at BEFORE UPDATE ON products
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_product_skus_updated_at BEFORE UPDATE ON product_skus

CREATE TRIGGER update_cart_updated_at BEFORE UPDATE ON cart
```

## 4. Row Level Security (RLS) 策略

启用 RLS 并通过 Supabase Service Role Key 在 Workers 层操作数据（绕过 RLS）。RLS 作为额外的安全防线，防止 anon key 直接操作数据。

```sql
-- 启用 RLS
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE categories ENABLE ROW LEVEL SECURITY;
ALTER TABLE products ENABLE ROW LEVEL SECURITY;
ALTER TABLE product_skus ENABLE ROW LEVEL SECURITY;
ALTER TABLE cart ENABLE ROW LEVEL SECURITY;
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
ALTER TABLE order_items ENABLE ROW LEVEL SECURITY;
ALTER TABLE addresses ENABLE ROW LEVEL SECURITY;
ALTER TABLE banners ENABLE ROW LEVEL SECURITY;
ALTER TABLE quick_icons ENABLE ROW LEVEL SECURITY;
ALTER TABLE home_products ENABLE ROW LEVEL SECURITY;
ALTER TABLE system_settings ENABLE ROW LEVEL SECURITY;

-- profiles: 已认证用户可读自己的数据
CREATE POLICY "profiles_select_own" ON profiles
    FOR SELECT USING (auth.uid() = id);

-- categories: 所有人可读
CREATE POLICY "categories_select_all" ON categories
    FOR SELECT USING (true);

-- products: 所有人可读上架商品
CREATE POLICY "products_select_active" ON products
    FOR SELECT USING (status = 'active');

-- product_skus: 所有人可读
CREATE POLICY "product_skus_select_all" ON product_skus
    FOR SELECT USING (true);

-- cart: 用户只能操作自己的购物车
CREATE POLICY "cart_select_own" ON cart
    FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "cart_insert_own" ON cart
    FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "cart_update_own" ON cart
    FOR UPDATE USING (auth.uid() = user_id);
CREATE POLICY "cart_delete_own" ON cart
    FOR DELETE USING (auth.uid() = user_id);

-- orders: 用户只能读自己的订单
CREATE POLICY "orders_select_own" ON orders
    FOR SELECT USING (auth.uid() = user_id);

-- order_items: 通过 orders 关联读取
CREATE POLICY "order_items_select_own" ON order_items
    FOR SELECT USING (
        EXISTS (SELECT 1 FROM orders WHERE orders.id = order_items.order_id AND orders.user_id = auth.uid())
    );

-- addresses: 用户只能操作自己的地址
CREATE POLICY "addresses_select_own" ON addresses
    FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "addresses_insert_own" ON addresses
    FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "addresses_update_own" ON addresses
    FOR UPDATE USING (auth.uid() = user_id);
CREATE POLICY "addresses_delete_own" ON addresses
    FOR DELETE USING (auth.uid() = user_id);

-- banners: 所有人可读启用的
CREATE POLICY "banners_select_active" ON banners
    FOR SELECT USING (is_active = true);

-- quick_icons: 所有人可读启用的
CREATE POLICY "quick_icons_select_active" ON quick_icons
    FOR SELECT USING (is_active = true);

-- home_products: 所有人可读
CREATE POLICY "home_products_select_all" ON home_products
    FOR SELECT USING (true);

-- system_settings: 所有人可读
CREATE POLICY "system_settings_select_all" ON system_settings
    FOR SELECT USING (true);
```

## 5. 数据库函数

### 5.1 生成订单编号

```sql
CREATE OR REPLACE FUNCTION generate_order_no()
RETURNS TEXT AS $$
DECLARE
    order_no TEXT;
BEGIN
    SELECT TO_CHAR(NOW(), 'YYYYMMDDHH24MISS') || LPAD(FLOOR(RANDOM() * 1000000)::INT::TEXT, 6, '0')
    INTO order_no;
    RETURN order_no;
END;
$$ LANGUAGE plpgsql;
```

### 5.2 生成商品编号

```sql
CREATE OR REPLACE FUNCTION generate_product_no()
RETURNS TEXT AS $$
DECLARE
    product_no TEXT;
    max_no TEXT;
    next_num INT;
BEGIN
    SELECT MAX(product_no) INTO max_no FROM products WHERE product_no LIKE 'P%';
    IF max_no IS NULL THEN
        next_num := 10001;
    ELSE
        next_num := (SUBSTRING(max_no FROM 2))::INT + 1;
    END IF;
    RETURN 'P' || next_num;
END;
$$ LANGUAGE plpgsql;
```

## 7. 索引策略总结

| 表 | 索引 | 类型 | 用途 |
|----|------|------|------|
| profiles | phone | UNIQUE | 手机号唯一 + 登录查询 |
| products | category_id | INDEX | 分类筛选 |
| products | status | INDEX | 状态筛选 |
| products | sales_count | INDEX DESC | 热销排序 |
| product_skus | product_id | INDEX | 查询商品规格 |
| cart | user_id | INDEX | 查询用户购物车 |
| cart | (user_id, product_id, sku_id) | UNIQUE | 防重复 |
| orders | user_id | INDEX | 查询用户订单 |
| orders | status | INDEX | 状态筛选 |
| orders | created_at | INDEX DESC | 时间排序 |
| addresses | user_id | INDEX | 查询用户地址 |
